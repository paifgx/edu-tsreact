# Task sheet 00 — Start and orientation

## Goal

Before you build the dashboard, you should be able to navigate the project confidently.

## Starting point

- The repository is freshly installed.
- The app runs locally.
- You are not working on features yet.

## Assignment

- Start the app with `npm run dev`.
- Open the project in your editor.
- Find the entry points `src/main.tsx` and `src/App.tsx`.
- Read `src/data/incidents.ts` and understand the domain types.
- Look at the prepared folders `src/components/`, `src/pages/`, `src/hooks/`, and `src/context/`.
- Start the mock API once with `npm run dev:api` so you know how it runs later.

## Done when …

- you see the app locally in the browser
- you know where the app entry, types, and seed data live
- you know how to start the mock API

## Notes

- Do not change domain logic in this sheet yet.
- The goal is orientation, not implementation.
